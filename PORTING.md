# Porting ntnsim to the HTML simulator

The core is written for a one-to-one JavaScript port: standard library only, plain dicts, no classes beyond small holders, and a portable random generator.

## Module map

| Python module | JS module | Notes |
|---|---|---|
| `rng.py` | `rng.js` | mulberry32 + Box-Muller (cached spare) + Knuth/normal Poisson + Rician power. Same seed gives identical draws in both languages; use this to cross-check the port. |
| `geometry.py` | `geometry.js` | Walker constellation, circular two-body propagation, look angles, range rate and range acceleration (analytic). `visibility_timeline` is the heaviest loop (sats x 8640 steps); run it in a Web Worker or precompute and ship as JSON (the `out/cache/*.json` files are exactly this). |
| `antenna.py` | `antenna.js` | `SatAntenna` becomes a factory returning `{g0, bw, gainToward(), gainOffbeam(), beamSpotArea(), tSys()}`. |
| `channel.py` | `channel.js` | TR 38.811 tables are constant arrays; linear interpolation in 10° steps. |
| `nbiot.py` | `nbiot.js` | TBS table, RU structures, Pareto frontier (resource or airtime objective), segmentation. Precompute the frontier once per case. |
| `refsched.py` | `refsched.js` | Optional in the browser (validation tool); the FIFO and priority loops port directly. |
| `phy.py` | `phy.js` | LoRa time on air (AN1200.13), LR-FHSS frame, cellular Eb/N0 rate model. |
| `interference.py` | `interference.js` | Ring integration (200 rings). Cache per 10° elevation bin as in `Case.i0`. |
| `access.py` | `access.js` | Target-centric Monte Carlo. `Pool` = array plus mean/std. |
| `energy.py` | `energy.js` | State-time energy and battery life. |
| `presets.py` | `presets.json` | Generated by `presets.export_presets()`; the UI reads it. |
| `engine.py` | `engine.js` | `Case` and `run_case`. Keep pass 1 (geometry/link) and pass 2 (access) separate so a progress bar can update between them. |
| `analysis.py` | `analysis.js` | Closed form except `capacity` and `goodput_curve` (Monte Carlo). |
| `report.py`, `figures.py`, `validate.py` | not ported | The HTML version draws its own charts; reuse `validate.py` values as unit-test expectations. |

## Suggested UI controls (mirror the notebook form)

Stack, scenario, satellite class, constellation, device power, device antenna gain, device-side loss, polarisation loss, ISM activity level, terrestrial coexistence mode, transmit policy and minimum elevation, load scale, Monte Carlo samples.

## Suggested HTML views

1. Link budget table at a chosen elevation (closed form, instant).
2. Path loss, margin, coverage probability and throughput versus elevation (closed form, instant).
3. Cell radius and time coverage (closed form plus cached timeline).
4. Interference noise rise versus density (closed form).
5. Delivery, latency, energy (Monte Carlo, 1-3 s in a worker).
6. Goodput and capacity curves (Monte Carlo sweep, run on demand).

## Cross-check procedure

Run `run_case(stack, scen)` in Python and JS with the same seed and `n_mc`; results must agree to floating-point rounding. Any difference means a porting error, not randomness.
